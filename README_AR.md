# Flashy+ — مشروع أندرويد

تطبيق بسيط للتحكم في فلاش الهاتف. الاسم والأيقونة من تصميم المشروع.

## المزايا
- تشغيل وإطفاء الفلاش من داخل التطبيق.
- محاولة تبديل الفلاش عند الضغط المطوّل على زر **رفع الصوت** لمدة تقارب 0.5 ثانية.
- واجهة عربية داكنة.

## طريقة فتح المشروع
1. فك ضغط الملف.
2. افتح مجلد `FlashyPlus` في Android Studio.
3. انتظر مزامنة Gradle ثم اختر Build > Build APK(s).
4. ستجد ملف APK عادةً في `app/build/outputs/apk/debug/`.

## الإعداد على الهاتف
1. ثبّت التطبيق وامنحه إذن الكاميرا.
2. افتح التطبيق واضغط «تفعيل زر رفع الصوت».
3. من إعدادات إمكانية الوصول، اختر `Flashy+` وفعّل الخدمة يدوياً.
4. جرّب الضغط المطوّل على زر رفع الصوت.

## تنبيهات مهمة
- هذه حزمة **مصدر المشروع** وليست APK جاهزاً.
- نظام أندرويد يفرض تفعيل خدمة إمكانية الوصول يدوياً، وقد تختلف قدرة التقاط زر الصوت حسب إصدار أندرويد والشركة المصنّعة.
- تفعيل الخدمة يجعل التطبيق يتلقى أحداث زر الصوت لأداء الوظيفة المطلوبة؛ لا يقرأ التطبيق محتوى الشاشة ولا يرسل بيانات.
- قد تمنع تطبيقات أو أوضاع معينة التقاط الزر، وقد يتعارض حجز زر رفع الصوت مع التحكم المعتاد في مستوى الصوت أثناء الضغط.
- عند حدوث تعارض مع تطبيق الكاميرا، أغلقه ثم أعد المحاولة.
